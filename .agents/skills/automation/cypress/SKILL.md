# Cypress

- Utilizar selectores estables.
- Evitar `cy.wait()` con milisegundos como sincronización principal.
- Mantener los tests independientes.
- Reutilizar lógica común cuando aporte valor.
- Priorizar flujos críticos y regresiones repetitivas.
