# Best Practices

- Mantener el código simple y legible.
- Evitar duplicación innecesaria.
- Utilizar nombres descriptivos.
- Mantener los tests independientes.
- Evitar esperas fijas cuando exista una condición verificable.
- Priorizar mantenibilidad sobre soluciones excesivamente complejas.
