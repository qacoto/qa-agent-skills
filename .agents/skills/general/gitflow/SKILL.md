# GitFlow

## Branches

```text
feature/<ticket>-<descripcion>
bugfix/<ticket>-<descripcion>
hotfix/<ticket>-<descripcion>
release/<version>
```

## Pull Requests

Un PR debería indicar:

- objetivo;
- alcance;
- validaciones realizadas;
- riesgos conocidos.
